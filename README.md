## Introduction

The Pika data kit (Pika) is a **spatial data collection product** for **embodied AI**. It is a lightweight, portable, capture-and-execute solution for general manipulation, consisting of a capture device, a model-inference actuator, a localization base station, and a data backpack. It supports efficient, accurate, fast, and lightweight collection of robot spatial manipulation data.

Pika provides **millimeter-level spatial sensing**, covering 6-DoF pose, depth, ultra-wide-angle RGB, and gripper state. This meets the **multi-modal data fusion** needs of embodied AI. The actuator can run model inference from data collected by the capture device.
